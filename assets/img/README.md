# Куда класть фотографии

## Папки
- `team/` — портреты тимлидов и преподавателей
- `gallery/` — фотоотчёты со встреч

## Требования
| Что | Размер | Формат |
|---|---|---|
| Портрет в «Команду» | 600×600, квадрат, лицо по центру | `.webp` или `.jpg` |
| Фото в галерею | ширина ~1600, горизонтальные | `.webp` или `.jpg` |
| Обложка hero | 2000×1200 | `.webp` или `.jpg` |
| Превью для мессенджеров | 1200×630 | `.jpg` |

## Имена файлов
Только латиница, без пробелов, строчными буквами через дефис:

```
team/anna-ivanova.webp
gallery/olympiad-2026-01.webp
```

Кириллица и пробелы в именах на части хостингов ломают ссылки.

## Как фото попадут на сайт
Сейчас в `index.html` стоят заглушки `<div class="photo-slot">`. После того как файлы окажутся в этих папках, они заменяются на `<img src="assets/img/...">` — вёрстка и размеры уже подогнаны.
