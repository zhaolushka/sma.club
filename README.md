# Клуб математики — лендинг

## Файлы
- `index.html` — разметка всех секций
- `styles.css` — стили
- `script.js` — мобильное меню
- `assets/img/` — фотографии (см. `assets/img/README.md`)

## Как открыть
Открыть `index.html` в браузере. Шрифты подтягиваются с Google Fonts, поэтому нужен интернет.

## Что нужно, чтобы наполнить сайт
1. **Фото** — в `assets/img/team/` и `assets/img/gallery/`.
2. **Тимлиды** — на каждого: имя, роль, одна-две строки о себе, контакт.
3. **Расписание** — дни, темы, уровень, место проведения.
4. **Достижения** — год, событие, результат, имена.
5. **Контакты** — адрес, почта, телеграм, часы работы.

## Иконки
Все иконки — inline SVG в спрайте в начале `index.html` (`<symbol id="i-...">`), никаких внешних библиотек и шрифтов. Вставляются так:

```html
<svg class="ico"><use href="#i-book"/></svg>
```

Размер берётся от `font-size` родителя, цвет — от `color` (через `currentColor`), поэтому иконка подстраивается под текст рядом. Доступные id: `i-ruler`, `i-pencil`, `i-bulb`, `i-arrow-ur`, `i-sliders`, `i-plus`, `i-search`, `i-message`, `i-thumb`, `i-camera`, `i-menu`, `i-close`, `i-book`, `i-file`, `i-video`, `i-link`, `i-download`, `i-mail`.

Новую иконку добавлять так: скопировать пути из [Lucide](https://lucide.dev) в новый `<symbol>` с `viewBox="0 0 24 24"` — набор нарисован в том же стиле (обводка, скруглённые концы).

## Книги и материалы
Секция `#library` состоит из трёх частей: лавандовая панель `.lib-panel` с полкой книг, белая карточка `.lib-sheet` с подборкой и список ссылок `.link-row`.

Обложки нарисованы вёрсткой, картинки не нужны. Чтобы добавить книгу, скопируйте один `.shelf-item`:

```html
<div class="shelf-item" data-cat="geo">
  <div class="cover cv-c"><span class="cv-t">Название</span><span class="cv-by">Автор</span></div>
  <div class="s-meta">Уровень</div>
</div>
```

- `data-cat` — категория: `geo`, `comb`, `num`, `obz`. Счётчики в табах считаются из этих атрибутов в `script.js`, вручную их править не нужно; при добавлении новой категории добавьте кнопку `.cat` с тем же `data-cat`.
- `cv-a`–`cv-f` — оформление обложки: кремовая, оранжевая, фиолетовая, белая, бирюзовая, тёмная.
- Высота обложек задаётся переменной `--cvh` у `.shelf-wrap`; стеклянная полка `.shelf-glass` подстраивается под неё автоматически.

При наведении книга выезжает вверх из полки на 36 пикселей. Над обложкой заранее оставлено пустое место (`.shelf-item .cover { margin-top: 36px }`), поэтому подъём не обрезается горизонтальной прокруткой. Планка `.shelf-glass` остаётся на линии полки. Клик оставляет книгу поднятой классом `.selected`.

## Форма заявки
В `index.html` у формы стоит заглушка `action="https://formspree.io/f/ВАШ_ID"`. Чистый HTML письма не отправляет, поэтому нужен посредник: зарегистрироваться на [Formspree](https://formspree.io), создать форму и подставить её идентификатор. Пока это не сделано, работает ссылка на почту под формой.
